# GitHub 项目雷达

一个私人维护的中文 GitHub 项目归档网站。包含每日快照、统一项目库、搜索、分类、收藏及项目历史。

## 站点功能

- **每日雷达**：按日期保留日报，保留当时刊载的热度值。
- **项目库**：以 `owner/repo` 为唯一键合并历史上榜记录，支持全文搜索、分类和排序。
- **项目档案**：显示简介、历史上榜、原仓库入口、技术标签与重要限制。
- **收藏**：当前采用浏览器 localStorage，跨设备不自动同步。
- **响应式**：桌面与手机均可使用，完全静态，不需要数据库或构建步骤。

## 本地预览

在仓库根目录执行：

```sh
python3 -m http.server 8000
```

打开 `http://localhost:8000/`。

## 目录

- `index.html`：站点入口
- `assets/styles.css`：样式和响应式布局
- `assets/app.js`：路由、搜索、过滤、收藏与项目详情
- `data/history.js`：历史日报和项目条目（浏览器可直接载入）
- `scripts/validate-data.mjs`：纯 Node.js 数据完整性检查

## 隐私与发布

仓库当前为 **Private**；本仓库不会自动改变可见性，也不自动公开部署。

注意：**私人 GitHub 仓库不等于私人网站。** GitHub Pages 对私人仓库的支持取决于 GitHub 付费方案，且普通 Pages 页面通常公开可访问。若希望只有自己访问，应另外配置带认证的托管方案；不要把 GitHub 密钥、模型 API Key 或私密内容写入前端或静态数据。

## 历史数据声明

初版收录 2026-10-10 至 2026-10-16 的已有雷达快照，部分历史热度和描述来自此前人工整理的日报，**不是在本站首次提交时重新读取 GitHub Trending 得到的实时值**。历史记录不应被理解为已经独立复核。

日报自动发现/核验/AI 摘要尚未启用；后续需连接经过测试的采集流水线，不能靠静态站点自行每天更新。
