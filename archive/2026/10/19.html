01

ai-memory↗

★ 10,035 Stars

跨 Claude Code、Codex 和 OpenCode 的持久化工程记忆与任务交接。

通过 Rust 服务和 Git 版本化的 Markdown 文件保留项目背景、决策、任务进度及代理交接资料，供 Claude Code、Codex、OpenCode 等在后续会话查询。支持 MCP 与生命周期 Hook，目的是让任务换工具或重新开启对话时不必从头解释。适合多仓库长期开发；需维护索引与同步方式，项目对 Windows 原生运行仍有实验性说明。

MIT；正式 Release v3.1.0 发布于 2026-10-16。

02

Hy-Memory↗

🇨🇳新项目

腾讯开源的分层长期记忆引擎与 MemHub 桌面/CLI。

腾讯的长期记忆组件，将聊天偏好、正在处理的工作状态和代码相关知识分成不同记忆层。配套 MemHub 界面与 CLI，可从获授权的编码代理会话提取可复用信息，并通过 SDK 配合向量检索。适合让多个 Agent 共享项目上下文；对话是否值得保存、来源权限及错误记忆的纠正仍需要明确策略。

Apache-2.0；README 列出 2026 年 10 月 Hy Memory 2.0.4、MemHub v1.0.4。

03

MOSS-Image↗

🇨🇳新项目

OpenMOSS 的 5B 图像生成模型，侧重图中排版及文字。

OpenMOSS 公开的约 5B 参数图像生成模型，重点研究在画面中布局多个元素和绘制可读文字。提供基础权重、SFT 版本以及 LoRA 等微调路径，并有 ComfyUI 接入方案，适合海报排版、图文混合和版式实验。效果会受提示词、图像尺寸及推理显存限制影响，作者演示不能替代自己的实际测试。

仓库代码 Apache-2.0；模型权重和实际显存需求应分别核对；2026-10-16 公开模型，独立 GitHub Release 版本未确认。

04

AutoIllustrate↗

🇯🇵新项目

日本 Sakana AI 将研究方法描述生成可编辑学术图。

把论文里的实验装置、算法流程或研究概念描述转成可修改的学术插图。流程先生成 draw.io XML 等结构化可编辑图，再视需要调用图像模型润色或导出图片，保留后期调整文字、箭头和布局的空间。适合研究报告、论文配图和讲座材料；运行涉及 Node.js、Python 及配置的 AI 接口，成图仍要核对学术含义。

Apache-2.0；默认流程需要付费模型 API，运行代理有命令执行权限；GitHub Release 版本未确认。

05

Scout↗

新项目

可用自然语言驱动真实浏览器完成网页任务的开源 Agent。

面向真实网页操作的浏览器 Agent，可用自然语言提出目标，再由工具在浏览器中导航、点击、填写表单并读取结果。支持本机浏览器或托管浏览器路径，接口兼容多种模型服务；适合重复查资料、提取公开信息和验证网页流程。页面登录态与敏感操作需要授权，网站结构变化可能导致任务失败。

Apache-2.0；云端浏览器额度与语言模型费用分开计算；GitHub Release 版本未确认。

06

Furifont↗

新项目

无需 ruby 标签的日语振假名字体。

将日语汉字的振假名信息通过 OpenType 字体能力预先组织，减少在普通网页里逐字添加 HTML ruby 标记的工作。提供不同衬线风格、可变字体、WOFF2 和辅助脚本，适合日语阅读网页与排版实验。字体内置覆盖和读音规则有限，多音字、专有名词及上下文读法仍可能需要人工标注。

代码 MIT；词典 CC BY-SA 4.0；语境多音字可能标注错误；README 提供 Release 下载入口。

Native Shell↗

新项目

Rust + TSX 的原生跨平台 UI 引擎 Native Shell。

实验性跨平台原生 UI 引擎，用 TypeScript/JSX 描述界面，再映射到 iOS UIKit、Android Views、macOS AppKit、Windows Win32、Linux GTK 或 Web。目标是让业务逻辑与界面结构尽量复用，同时保留系统原生控件。适合研究统一 UI 描述层与多端组件，实际平台支持、布局一致性和构建环境需要分别测试。

Apache-2.0（LICENSE-APACHE）；跨平台支持仍需按目标系统构建实测。

ComfyArt↗

🇨🇳新项目

ComfyUI 内运行的本地 AI 设计画布。

在 ComfyUI 工作流周围加入类似设计软件的无限画布，借助 React 和 tldraw 操作图层、素材和 AI 生成节点。可组织图像与视频内容，并导出图片、PDF 或可编辑的 PPTX，适合反复拼版、标注和整理生成结果。需要已有 ComfyUI 模型及工作流；大尺寸素材与多模型任务仍受硬件资源限制。

MIT；图像生成取决于本地 ComfyUI 模型和 GPU；Release 版本未确认。

09

Indra OCR↗

新项目

针对 CPU 优化的小型 OCR 模型 Indra。

为 OCR 场景优化的小型识别模型，使用 ONNX Runtime 处理扫描页面和图片，输出可供后续处理的 Markdown 或结构化结果。适合批量文档识别、建立可搜索语料以及在 CPU 资源有限的环境做实验。作者提供页面吞吐基准，但实际速度受分辨率、版面复杂度和 CPU 类型影响，公式与表格通常仍需抽查。

代码 Apache-2.0；模型权重是修改版 OpenRAIL-M：对商用规模和与官方 API 竞争的用途有额外限制；复杂表格和手写识别也有限制。

Endo↗

新项目

将不同订阅的编码 Agent 组织为一个工作流。

把不同 AI 编码订阅与 CLI 工具连接成可持续的工作流，支持在 Claude Code、Codex、Grok 等之间切换、并行分工和续接已有会话。可用于把调研、实现和审查分给不同代理，避免每换一个模型就重新整理背景。使用者需要管理各代理的登录状态、调用额度及并发修改同一仓库时的冲突。

MIT；现有直接下载面向 macOS Apple Silicon；从源码构建需 Node 24/Bun/Just。

OpenScion↗

新项目

面向高并发编码 Agent 的服务端版本控制。

研究在大量 AI 编码代理并发工作时如何降低传统 Git 完整克隆和提交合并的成本。Rust 实现关注按需对象获取、服务器端变更集、rebase 与历史管理，让各代理只取得当前需要的代码状态。适合大仓库、多工作树和云端代理环境的版本控制实验；与现有 Git 服务、权限和备份机制的兼容性要单独验证。

GPL-3.0-only；独立实现，作者合成基准不代表生产环境已验证。

13

Handwired↗

新项目

将普通 JS 条件分支和状态运算映射为可微分的矩阵计算。

把 JavaScript 中的条件判断和状态更新改写为可进行梯度计算的数学表达，探索将一般程序逻辑迁移到 GPU 并用于学习或优化。通过算术变换、ReLU 与 WebGPU 等手段处理可微分路径，适合研究可微分编程和硬件并行。属于计算实验，不代表任何 JavaScript 程序都可无损转换，也不适合作为普通网页加速器。

MIT；探索性研究/演示，性能收益取决于具体程序；Release 版本未确认。
