xtool↗

xtool-org/xtool

跨平台构建、签名和安装 iOS 应用的工具。

围绕 Swift Package Manager 提供跨平台 iOS 应用构建、签名、安装与设备运行命令，使开发者不必把所有操作都绑在 Xcode 图形界面里。可管理连接设备、IPA 安装及启动，也可以作为 Swift 库集成。实际签名与真机运行仍需要 Apple 开发证书、配置文件和匹配的系统工具，不能绕过 iOS 签名要求。

Windows 主要经 WSL 使用；签名仍需有效凭据。

Tencent/BrowserSkill CN

让 Agent 操作已经登录的 Chrome 和 Edge。

通过浏览器扩展与本地 CLI，让 AI Agent 操作用户已经登录的 Chrome 或 Edge，而不是重新打开一个没有 Cookie 的隔离浏览器。支持读取页面、截图、填写表单和触发点击，适合在授权情况下自动处理熟悉的网站流程。由于复用现有登录状态，必须限制 Agent 能访问的网站以及支付、删除等敏感动作。

会获得网页操作权限，应谨慎处理敏感后台会话。
