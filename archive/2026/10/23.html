01

xerj

★ 13,107 Stars

Rust 本地代码和文档索引：BM25、混合检索、MCP 与 Elasticsearch 兼容接口；避免 Agent 反复遍历文件。

使用 Rust 建立本地代码、PDF、日志和结构化资料索引，让 Coding Agent 通过 MCP 查询相关文件、符号和精确行号，而非每次把整个项目读进上下文。支持 BM25 词法检索及可选的混合/向量检索，并提供兼容部分 Elasticsearch 的接口。适合多仓库知识查询；启用神经检索会增加额外模型与资源需求。

02

net-merge

★ 1,778 Stars

将 Wi-Fi、有线网、手机热点按连接分摊给不同流量，适合并发下载。

将机器的 Wi-Fi、有线网和手机热点等多条网络连接分别分配给不同 TCP/UDP 会话，以改善并行下载或多连接应用的总吞吐。支持 Windows、macOS 和 Linux，重点在按连接分流而不是要求上游提供合并服务器。适合多个连接同时活动的场景；单条 TCP 下载或单个视频连接一般不会自动获得多条线路带宽之和。

03

wxa-runner

★ 496 Stars

使用微信官方基础库在浏览器运行小程序编译产物，支持 Chrome DevTools、Playwright 无头测试。

把微信小程序构建产物放进浏览器环境运行，结合微信基础库、Chrome DevTools 和 Playwright 做自动化验证。支持在测试中模拟登录状态、请求响应及页面生命周期，比单靠微信开发者工具手动点测更适合 CI。它不能代替微信官方上传审核、真机兼容性或账号权限检查，使用基础库也应遵守相应授权。

04

Furifont

★ 392 Stars

把振假名画入字体，通过 OpenType 连字为日文自动标注读音，无需修改网页文本。

将日语汉字的振假名信息通过 OpenType 字体能力预先组织，减少在普通网页里逐字添加 HTML ruby 标记的工作。提供不同衬线风格、可变字体、WOFF2 和辅助脚本，适合日语阅读网页与排版实验。字体内置覆盖和读音规则有限，多音字、专有名词及上下文读法仍可能需要人工标注。

05

Koharu

★ 6,456 Stars

整合漫画文字检测、OCR、翻译、去字修复、竖排排版和 PSD 导出的 Rust 本地工具。

把漫画翻译的多个步骤放到一个本地工具里：检测对话框和文字、OCR 识别、翻译、去除原文、重新排版，并导出可以继续修订的 PSD。支持整册图片、压缩包和 PDF 的逐页工作流，可连接本地 GGUF 或在线模型。适合需要保留版面可编辑性的翻译工作；复杂字体、竖排文字和图像修补仍可能产生错误。

06

handwired

★ 1,928 Stars

将普通 JavaScript 条件与循环编译为矩阵乘法、ReLU 等可微分计算。

把 JavaScript 中的条件判断和状态更新改写为可进行梯度计算的数学表达，探索将一般程序逻辑迁移到 GPU 并用于学习或优化。通过算术变换、ReLU 与 WebGPU 等手段处理可微分路径，适合研究可微分编程和硬件并行。属于计算实验，不代表任何 JavaScript 程序都可无损转换，也不适合作为普通网页加速器。

07

Scout

★ 940 Stars

开源浏览器 Agent，可根据自然语言操作真实网页并返回结果。

面向真实网页操作的浏览器 Agent，可用自然语言提出目标，再由工具在浏览器中导航、点击、填写表单并读取结果。支持本机浏览器或托管浏览器路径，接口兼容多种模型服务；适合重复查资料、提取公开信息和验证网页流程。页面登录态与敏感操作需要授权，网站结构变化可能导致任务失败。

08

MOSS-Image

★ 1,451 Stars

5B 参数文生图基础模型，关注图中文字渲染、可控布局和微调。

OpenMOSS 公开的约 5B 参数图像生成模型，重点研究在画面中布局多个元素和绘制可读文字。提供基础权重、SFT 版本以及 LoRA 等微调路径，并有 ComfyUI 接入方案，适合海报排版、图文混合和版式实验。效果会受提示词、图像尺寸及推理显存限制影响，作者演示不能替代自己的实际测试。

Claude 风格 React 组件、设计令牌与交互动效，并附逆向设计研究手册。

整理接近 Claude 视觉风格的开源组件、CSS 设计令牌和 React/Tailwind 示例，便于在自己的应用中复用对话区、工具条、边栏和消息呈现形式。项目通过对现有界面行为的研究还原交互细节，适合快速搭建 AI 聊天产品原型。它是社区重建的界面资源，不是 Anthropic 官方发布的 Claude 客户端。
