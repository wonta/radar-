Stars 为 GitHub 采集快照，并非日增；README 所述能力尚未逐项实机验证。

今日速览（12 项）
  1. deepseek-ai/DeepInfer 面向 DeepSeek 大规模推理，带 MoE 并行与异步调度；仅列 SM100 与 Ascend 950，非家用推理方案。
  2. Niko1221/Strata 本地大模型推理与 OpenAI/Anthropic API；官方推荐至少 12 GB 显存，8 GB RTX 4060 不属于推荐配置。
  3. tangency-labs/solidcraft Rust 参数化 CAD：草图、几何约束、特征时间线及 MCP；适合制作可修改尺寸的 3D 打印零件。
  4. cdcailf/cjkfold 正规化 PDF 提取文本中的形近 CJK 部首，弥补 NFKC 漏掉的字符，改善中文全文检索和 RAG。
  5. init-co-jp/diff-tour 把 Git diff 做成互动式代码审查导览，帮助理解回滚、权限、幂等性与测试风险；依赖已有 Coding Agent。
  6. useopendesk/opendesk 可自托管的共享客服邮箱、工单、在线聊天与知识库；使用 Go、Elixir、PostgreSQL 等多组件。
  7. pengchujin/aerial-tv 国产 Android TV 无广告桌面与航拍屏保，有部分小米、TCL、索尼实机记录；在线视频依赖网络。
  8. mu-zi-lee/Tangentry 本地 SQLite 保存跨 B站、YouTube、播客和 RSS 的阅读与时间锚定笔记，可导出 Markdown。
  9. T-Crypt/berth 为同一 GPU 上的 AI 服务按租约排队分配显存；Linux 支持较完整，Windows 仍属实验阶段。
  10. xiaoyang111222/cn-math-taxonomy 中小学数学知识点与先修依赖图谱；AI 生成初稿未经过教师审核，采用非商业许可。
  11. charlie5188/css-composite-font 浏览器内调整汉字、假名、欧文的字体尺寸、基线和字重并导出 CSS/字体；注意字体授权。
  12. google-research/harness2 自动尝试并改进 Agent 的提示词、工具和技能组合；官方基准未经独立复测，模型调用有成本。
