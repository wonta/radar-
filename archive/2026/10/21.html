deepseek-ai/DeepInfer

面向 DeepSeek 大规模推理，带 MoE 并行与异步调度；仅列 SM100 与 Ascend 950，非家用推理方案。

面向大规模 DeepSeek 推理的基础设施，研究混合专家模型的并行计算、异步任务调度和服务吞吐，目标设备包括服务器级 NVIDIA SM100 与 Ascend 950。适合研究多 GPU 推理架构和集群性能，不是让普通 8GB 显存显卡一键运行 DeepSeek 的桌面应用；实际部署要匹配特定加速硬件和运行时。

本地大模型推理与 OpenAI/Anthropic API；官方推荐至少 12 GB 显存，8 GB RTX 4060 不属于推荐配置。

在本地设备启动大语言模型，并通过兼容 OpenAI 或 Anthropic 的接口向应用暴露推理服务，可用于对话工具或 Coding Agent 的模型后端。项目更偏向独立推理服务而非只提供聊天窗口；官方建议至少 12GB 显存，8GB RTX 4060 不属于推荐配置，是否可以用量化模型运行需要另测。

tangency-labs/solidcraft

Rust 参数化 CAD：草图、几何约束、特征时间线及 MCP；适合制作可修改尺寸的 3D 打印零件。

Rust 编写的参数化 CAD 项目，强调草图尺寸约束、特征时间线和可回改的几何建模过程。通过 MCP 等接口，让 AI 工具按明确尺寸生成、修改或检查模型，适合制作可持续调整的 3D 打印零件与机械概念件。参数化建模比一次性网格生成更可编辑，但复杂特征、导出格式和求解稳定性仍要实测。

cdcailf/cjkfold

正规化 PDF 提取文本中的形近 CJK 部首，弥补 NFKC 漏掉的字符，改善中文全文检索和 RAG。

解决从 PDF 或网页提取的 CJK 文本出现形近部首、兼容字或错误 Unicode 形态时，普通 NFKC 正规化仍无法统一搜索的问题。工具针对可识别的字形变体做额外归并，改善中文检索、全文索引与 RAG 文本匹配。它不会理解词义，也可能把确有区分的字符合并，重要文献应保留原文。

init-co-jp/diff-tour

把 Git diff 做成互动式代码审查导览，帮助理解回滚、权限、幂等性与测试风险；依赖已有 Coding Agent。

把 Git diff 和代码审查建议组织成可交互的逐步导览，帮助开发者重点检查权限、回滚、幂等性、测试覆盖与修改影响。适合让 Coding Agent 先整理变化，再由人逐项确认，避免在大量无关行中迷失。依赖提供的代码上下文与代理能力，不保证自动发现全部潜在问题。

整合共享客服邮箱、在线聊天、工单分配和知识库，让小团队从一个界面跟进客户问题，而不是将不同渠道散在多个工具中。项目含 Go、Elixir、PostgreSQL 等服务，适合需要自主控制数据的客服场景。多组件部署带来运维成本，邮件送达率、权限和备份恢复需要单独配置。

国产 Android TV 无广告桌面与航拍屏保，有部分小米、TCL、索尼实机记录；在线视频依赖网络。

面向 Android TV 的类 tvOS 电视桌面，把常用应用、HDMI 信号源和文件夹集中管理；可用遥控器整理图标，也能扫描二维码从手机上拖动排序、改名或隐藏应用。附带航拍屏保、时钟、壁纸和个性化显示，部分设备可播放 4K 航拍视频。替换桌面通常需要 ADB 或设备允许设置默认 Launcher；原厂开机广告未必能消除，项目明确不支持 LG webOS、三星 Tizen 和部分其他系统。

mu-zi-lee/Tangentry

本地 SQLite 保存跨 B站、YouTube、播客和 RSS 的阅读与时间锚定笔记，可导出 Markdown。

用本地 SQLite 保存跨 B站、YouTube、播客与 RSS 的阅读和观看线索，把笔记绑定到视频/音频的具体时间点或文章位置。可导出 Markdown，适合反复整理技术讲座、教程与播客中的关键内容。不同平台内容的提取能力及本地同步方案需确认，链接仍可能因原平台删除或访问限制失效。

T-Crypt/berth

为同一 GPU 上的 AI 服务按租约排队分配显存；Linux 支持较完整，Windows 仍属实验阶段。

为同一张 GPU 上的多个 AI 服务分配显存租约，避免不同推理进程随意争抢资源引发 OOM。通过排队、租用和释放机制管理资源，适合在一台机器轮流跑多个模型工具。项目对 Linux 支持更完整，Windows 属实验范围；它不能增加物理显存，也不能替代模型本身的显存优化。

把中文中小学数学拆分成知识点以及“学习某知识前需要掌握什么”的先修关系，可用来构建知识地图、题目标签和自适应练习路线。适合教育内容检索、学习薄弱点分析以及课程编排原型。仓库说明数据初稿含 AI 生成部分，且有非商业许可限制；概念划分、课程适配及关系正确性需要教师或教研人员复核。

浏览器内调整汉字、假名、欧文的字体尺寸、基线和字重并导出 CSS/字体；注意字体授权。

提供浏览器里的 CJK 混排字体调整工具，可分别选用中文汉字、日文假名和拉丁字形，调整字号、字重、基线并导出可复用的 CSS/字体设置。适合做中文日文混排网站，解决不同字体视觉高度不一致的问题。导出字体时须检查源字体许可和浏览器加载性能。

自动尝试并改进 Agent 的提示词、工具和技能组合；官方基准未经独立复测，模型调用有成本。

探索自动评估和优化 AI Agent 的运行配置，包括提示词、工具选择和技能组合。通过反复执行测试任务比较结果，帮助找到某类任务更合适的 Agent 设定；适合研究代理性能与可复现评测。运行基准和模型调用会产生成本，作者实验成绩不能直接代表所有任务的表现。
