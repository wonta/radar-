Headroom↗

headroomlabs-ai/headroom

压缩发往大模型的工具输出、日志和检索内容。

专门削减 AI 模型上下文中冗长的工具输出、日志和检索结果，提供 Python、TypeScript 接口、CLI、代理模式以及 MCP 连接。系统会按内容类型压缩，同时保留原文供需要时按引用取回，目标是降低无用 Token 占比。适合使用大量终端命令和检索工具的 Agent；压缩可能隐藏重要细节，作者节省比例需按自己任务验证。

Apache-2.0；v0.41.0（10月14日）。

CleanYourTV↗

Gathin23/cleanyourtv

通过无线 ADB 精简 Android TV/Google TV 预装组件并更换启动器。

通过 Wi-Fi ADB 连接 Android TV 或 Google TV，检查并停用部分厂商预装软件、首页推荐与广告相关组件，也可辅助切换启动器。不要求 Root，通常以停用而非永久删除方式处理，便于恢复。适合希望清理电视首页又不想刷机的用户；需要按设备型号查看支持情况，误停系统服务可能使遥控器、设置或主页异常。

MIT（直接核对 LICENSE）；v2.3.0（10月19日）。

net-merge↗

rohit267/net-merge

将多条网络连接按 TCP/UDP 会话分流，利用多个网卡。

将机器的 Wi-Fi、有线网和手机热点等多条网络连接分别分配给不同 TCP/UDP 会话，以改善并行下载或多连接应用的总吞吐。支持 Windows、macOS 和 Linux，重点在按连接分流而不是要求上游提供合并服务器。适合多个连接同时活动的场景；单条 TCP 下载或单个视频连接一般不会自动获得多条线路带宽之和。

MIT；v0.3.2（10月19日）；安装会涉及系统网络路由。

Leonxlnx/earshot

让 Coding Agent 在 CPU 上分析、比较、定位和合成声音。

面向 Coding Agent 的音频分析工具，提供 CLI、Python API 和 MCP，可做声音特征查看、声谱图、片段定位、相似音频比较及音效合成。适合让代理根据录音找出异响片段、比对两段声音或生成游戏音效，而不是只依赖文字描述。部分功能会在 CPU 上加载模型，第一次分析可能较慢，正式发行版本与 README 中列出的能力应核对。

MIT；v0.2.0（10月16日）。
