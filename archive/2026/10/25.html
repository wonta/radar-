01

public-apis↗

★ 491,890 Stars

按主题整理的免费公开 API 目录，便于开发者寻找可用接口。

由社区维护的免费公共 API 清单，按金融、天气、地图、影视、开发工具等主题分类，并标注接口地址、认证要求、HTTPS 等信息。开发者可据此快速寻找原型项目的数据源，而不必逐个搜索提供商。这里提供的是链接和目录，并不代管接口；实际调用额度、价格、稳定性和数据用途要以 API 官方说明为准。

02

freeCodeCamp↗

★ 457,859 Stars

提供免费互动编程课程与实践题，覆盖 Web 开发、计算机科学等主题。

课程在浏览器中分步骤练习 HTML、CSS、JavaScript、算法以及后端开发，提交代码后由自动测试检查结果，并通过实战项目完成认证。除交互课程外还有文章、视频和社区讨论。适合从零开始系统学习，而不只是下载一份教程；课程进度和认证依赖网站服务，中文覆盖程度会随课程变化。

03

free-programming-books↗

★ 400,018 Stars

按语言和主题整理可免费阅读的编程书籍、课程及资源。

这不是电子书下载器，而是由社区维护的免费编程资料索引。按编程语言、技术领域和自然语言分类，链接到电子书、在线课程、交互教程及编程练习；适合找某项技术的入门资料或系统教材。各资料由不同网站发布，阅读方式、许可条件和链接有效性需要分别核对。

04

openclaw↗

★ 392,961 Stars

可在自己的电脑上运行、通过常用聊天软件调用的 AI 助手。

在自己的电脑或服务器上运行统一的 Gateway，再从 WhatsApp、Telegram、Discord、Slack、iMessage 等聊天渠道向同一个 AI 助手发送任务。Gateway 管理会话、模型和工具调用；除了聊天，还能读取获授权的工作文件、调用本地命令、连接 MCP 服务，并通过桌面、手机或浏览器控制界面查看执行结果。 支持 Claude、Codex、其他在线模型及本地模型后端，可通过 Skills 和插件增加特定业务操作。适合把多平台聊天入口接到长期运行的个人助手上；初次安装需要配置模型、消息渠道身份和持久化工作目录。应特别注意：在主机模式下工具可能直接操作本机系统，必须限制陌生私信、聊天群、文件访问和自动执行权限；启用沙盒与配对验证比单纯开放公网入口可靠。

05

rea↗

★ 378,832 Stars

REA｜通过 MCP 将逆向工具接入 Claude Code、Codex 等 AI Agent，让智能体调查没有源码的软件功能。

通过 MCP 把 Claude Code、Codex 等 AI Agent 与逆向分析工具连接起来，让智能体调查没有源代码的软件。原生程序可结合 Ghidra、Hopper 或 IDA 查看伪代码、汇编、字符串、函数调用和交叉引用；Electron/JavaScript 可追踪模块、路由、preload 与 IPC；Android APK 可结合 JADX 检查清单、类和方法；网页可观察脚本和网络请求。适合研究某个软件功能的实际实现路径，并把调查证据交给编程助手复现。需要 Node.js/npm，部分目标还要安装 JDK、JADX 或原生分析器；工具不会自动恢复完整源码。

06

career-ops-ui↗

★ 88 Stars

面向 AI 求职工作流的网页控制台，集中搜索、分析和跟进职位。

为 career-ops 求职自动化流程提供可视化控制台，在一个网页里查看职位搜索、匹配评分、深入调查、投递任务和申请进度。支持对接 Greenhouse、Ashby、Lever 等招聘系统数据，并提供职位地图等浏览入口；适合同时跟踪大量岗位的求职者。它是 career-ops 工作流的前端，不等于自动保证获得职位，实际分析需要外部数据和配置的 AI 服务。

07

preloop↗

★ 79 Stars

给 AI Agent 的工具调用和模型调用增加审批与审计控制。

为 AI Agent 的 MCP 工具操作和模型调用增加统一的权限控制与审计层，可在高风险动作执行前请求人工审批，记录谁申请了什么操作、授权决定及调用结果。适合让 Agent 接入生产服务、内部数据或付费 API 时建立可追溯边界。需要按自己的环境配置工具代理、权限策略与审核人员；仅接入平台并不自动让所有外部工具安全。

08

delegatus↗

★ 33 Stars

把开发任务分派给 Codex、Claude Code 等编码 Agent 的任务看板。

把开发需求拆成可交给 Codex、Claude Code 等编码 Agent 的任务，集中查看每个任务的执行状态、需要人工处理的节点和最终结果。用户可以在浏览器或手机上安排工作、跟进进度并审阅输出，减少在多个终端窗口之间切换。适合多人或多 Agent 并行开发；代码质量、工作树冲突以及合并决策仍需开发者把关。

09

PawFlow-Agents↗

★ 26 Stars

自托管 Agent 运行平台，可访问文件、浏览器、桌面和外部服务。

提供可自己运行的 AI Agent 工作平台，用明确的工具权限连接文件操作、终端命令、浏览器、桌面控制和外部服务。支持多种模型与原生编码 CLI，还包含会话记忆、技能复用与需要确认的技能整理流程；可选对话内容加密。适合长期运行跨工具任务，但浏览器/桌面操作、密钥存储和远程访问的权限边界需要认真配置。

10

ProjectAchilles↗

★ 27 Stars

用于持续验证安全防护效果并量化网络风险的安全测试平台。

通过重复执行可验证的安全测试来衡量企业防护措施，而不是只给网络资产打静态风险分数。项目把威胁情报、安全验证步骤和结果报告串联起来，帮助团队发现现有检测与阻断规则的薄弱位置。适用于得到授权的安全评估与改进；测试范围、环境隔离及测试结果解释需要专业人员确认。

aurora↗

gpu-unlock↗

★ 3,013 Stars

Linux 内核模块，探索解除部分 NVIDIA RTX 30 系显卡的 FP16/BF16 吞吐限制。

Linux 内核模块，在显卡驱动初始化前调整部分 NVIDIA RTX 30 系（Ampere）GPU 的速度选择设置，目标是解除特定 FP16/BF16 运算吞吐限制。涉及内核模块、启动参数与 initramfs，适用于愿意做低层硬件实验的用户；不同驱动、GPU 和工作负载的效果不一样，Windows 不在其主要支持范围，修改启动流程存在风险。

REA-Prompts↗

★ 2,095 Stars

面向 REA 逆向分析工具的提示词合集，帮助 Coding Agent 分步调查程序。

为 REA 逆向分析工具配套整理可供 Coding Agent 使用的提示词和调查步骤，帮助代理从目标现象提出假设，再查看代码、调用关系与相关证据，而非直接猜测实现。适合想复用逆向调查流程、让多次分析结果更一致的用户。仓库提供的是工作指令而非新的反编译引擎，能力仍依赖 REA 和已安装的分析工具。
