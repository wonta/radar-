01

agent-autoloop↗

把命令行 AI Agent 变成事件驱动的后台任务执行器：自动接单、等待人工审批，再续接原会话。

采用 Node 24 与 TypeScript，内核将定时事件、Webhook、任务规则和执行回执分离；host/worker 负责启动 Agent，kernel/rules.ts 定义事件匹配、并发分组与访问权限。可通过 Claude Code、Codex、ACP 或通用命令适配器执行任务，决策卡片支持飞书等通知通道；等待答复时 Agent 进程退出，状态由日志与 SQLite 保留。适合自动处理 Issue、告警与定时工作。当前仅支持 macOS/Linux；仍需已登录的 Agent，模型额度照常消耗。

02

floci↗

在本机模拟多种 AWS 服务，让应用在不连接真实云账户的情况下进行开发与集成测试。

项目基于 Java Quarkus，提供 S3、SQS、SNS、DynamoDB、Lambda、API Gateway、Cognito、RDS 等服务的本地兼容接口。docker-compose.yml 将 4566 及多个代理端口映射到主机，并挂载 Docker socket 以创建辅助服务容器；应用可把 AWS SDK endpoint 指向本机。适合测试云端工作流、CI 和离线开发；它是模拟器而非 AWS 完全等价实现，使用 Docker socket 与大量端口时应隔离运行环境。

03

auto-ontology↗

为企业数据库自动构建可审查的业务语义图，再把自然语言问题转成可追溯的 SQL 查询。

先采集数据库结构、列样本与关系，抽取业务术语、SQL 属性及表间连接，保存到 Postgres/pgvector；人工可在界面中校订术语和计算口径。问答代理通过语义检索选取概念、验证过滤条件、生成并执行 SQL，同时展示查询步骤。Compose 包含 Postgres、pgAdmin、后端、摄取服务、前端和迁移任务。适合数据口径复杂的内部报表与问答；部署涉及数据库凭据和模型 API Key，自动推断的语义仍需业务人员审核。
